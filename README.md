# AdIntel — Ad Performance Intelligence Lab

Interactive, glassmorphism-styled dashboard for comparing ad spend, reach and return across companies, channels, regions and quarters.



- Charts: bar, doughnut, trend lines, efficiency bubbles, heatmap, radar — all recomputed in the browser from the data.
- Load your own CSV in the page (columns: company, channel, spend, impressions, clicks, conversions; optional region, quarter, revenue). Parsed locally.
- AI text (if present) is labelled, and each cited number was verified against a pandas calculation at build time.
- The demo data is **synthetic** (fictional companies).

No API keys are included in this repository. See `ATTRIBUTIONS.md` for credits.
